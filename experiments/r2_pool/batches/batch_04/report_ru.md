H16–H18 реализованы для S1. H19–H20 реализованы для S2. В каждой строке приведён основной вариант, объявленный до расчёта метрик. Сводный Pearson r² используется для парного сравнения с архивом. Каждая схема охватывает одну родительскую трубу. Ретроспектива S1 наследует совмещение по геометрии соседних участков на дату отсечения 2023-12-01. **H16.** Huber обучался на разнице между следующим измеренным минимумом и историческим аналогом базы. Входы включали прошлый профиль, разрыв между медианой и минимумом и размах P90−P10 внутри сегмента. Поправку центрировали на полной сетке по сегментам с прямыми измерениями. Отрицательные и положительные изменения толщины сохранялись в обучении. Вариант изменил 52 прогноза и снизил r² с 0,262284 до 0,094426 на четырёх сегментах и с 0,466294 до 0,378099 на 48 сегментах. Ridge с теми же признаками и квадратичной потерей дал **0,515147** по объединённым ключам. На отдельных участках он дал 0,106345 и 0,474745. Это контроль с противоположным результатом по функции потерь и повод для повторной проверки самого набора признаков. Повторных замеров одной точки для независимой оценки погрешности здесь нет. **H17.** Поправка исходного S1C умножалась на вес, выбранный по внутренней проверке на более ранних данных. Высокое покрытие означало минимум два прошлых замера в сегменте и два соседних сегмента с прямыми замерами в радиусе 20 м. Пары весов для низкого и высокого покрытия составили (0,5, 0) на участке из четырёх сегментов и (0,5, 0,5) на участке из 48. Все 52 отложенных сегмента имели высокое покрытие, поэтому эффективные веса составили 0 и 0,5 по участкам. Все прогнозы совпали с H12 и контролем единого веса. Дополнительный эффект сегментного доверия остаётся непроверенным. Для него нужна отложенная выборка с обоими уровнями покрытия. **H18.** К S1C добавлены медианные размеры старых дефектов в логарифме, распределение толщины внутри сегмента и доли категорий по прошлым записям. Использованы длина и ширина в мм в точке регистрации. Добавлена разность поправок расширенного и исходного S1C. На участке из четырёх сегментов r² вырос с 0,262284 до 0,292578, на участке из 48 с 0,466294 до 0,483496. H12 на участке из 48 дал 0,488333. Суммарная MAE выросла с 0,3725 до 0,4934 мм. Контроль с размерами и распределением толщины без категорий дал r² = 0,511489. Доля внешних дефектов была константой в обоих обучающих наборах. Вклад этой категории не оценён.
