**H36.** Для температурного профиля проверены три сценария коэффициента теплоотдачи: 0,3, 1 и 3 Вт/(м²·К). Выбор выполнен по среднему Pearson r² на внутренних отложенных участках. На ретроспективе выбран 3 Вт/(м²·К), фиксированный контроль 1 Вт/(м²·К) дал 0,040898 против 0,040965. Температурные признаки изменили 22 прогноза, для остальных 72 состав базы совпал. В 2018 году выбраны 1, 0,3 и 0,3 по участкам, сводный r² существенно ниже базы. Физические параметры остаются допущениями. H36 применена к S2. [Контроли](hypotheses/H36/summary.json) · [Внутренние прогнозы](S2_retro_2023/selection_inner_oof.csv)

**H37.** На внутренних прогнозах, где отложенный участок исключён из обучения базы, построено монотонное преобразование с максимумом пятью узлами. При прогнозе смесь с исходной формой центрируется и масштабируется по полной сетке, сохраняя исходные среднее и разброс до отсечения по физическим границам. На S1 итоговый r² снизился. Для S2 2023 монотонная карта стала плоской и процедура вернула базу. В 2018 году изменились четыре прогноза на одном участке, его r² снизился с 0,785111 до 0,755631. Небольшой сводный прирост на 372 строках этому участку не соответствует. [Форма карты и аудит](fit_audit.json) · [Метрики](hypotheses/H37/summary.json)

**H38.** Прогноз ограничен интервалом от P25 − 1,5 IQR до P75 + 1,5 IQR по полной сетке с соблюдением границ толщины. Для сравнения проверены мягкие физические границы с шириной 0,15 мм. На S1 основной вариант изменил две строки и ухудшил r². На S2 он изменил восемь прогнозов в ретроспективе и один в 2018 году. В ретроспективе на 31 сегменте r² вырос с 0,051214 до 0,051653, а на участках из 19 и 27 сегментов снизился. На 334 сегментах 2018 года r² вырос с 0,018791 до 0,019370. Контроль с мягкими границами дал 0,041968 и 0,008761 на двух схемах S2. [S2 по участкам, 2023](hypotheses/H38/S2_retro_2023/robust_iqr_cap/metrics_by_profile.csv) · [Все контроли](hypotheses/H38/summary.json)

**H39.** Группы признаков выбирались только по внутренним прогнозам. В S1 для участка из четырёх сегментов выбраны размеры старых дефектов, для участка из 48 сегментов — размеры и распределение толщины. Δr² по участкам составили −0,020580 и +0,010533. Сводный результат 0,508189 ниже полного H18 (0,511492). В S2 ретроспективная модель исключила абсолютную высоту и уступила базе. Контроль без координаты воспроизвёл 0,046349, известное по этапу 4. В 2018 году два отложенных участка получили полный состав признаков, крупнейший — вариант без абсолютной высоты, с локальным ухудшением. [Все варианты](hypotheses/H39/summary.json) · [Внутренние прогнозы S1](S1_peer_2023/feature_selection_inner_oof.csv)

**H40.** Смешаны поровну два прогноза с разными допущениями для раннего пробела. Первый сценарий принимает температуру грунта, второй переносит тепловую форму из первых 365 календарных дней с пригодными рядами. В ретроспективе крайние сценарии дали 0,040923 и 0,041159, смесь — 0,041042. В 2018 году все три варианта уступили базе. На целевой сетке сценарии меняют пространственную форму, но пригодная история в первых 365 днях занимает около одного дня, а ранний пробел — 21,5 года. Эта экстраполяция показывает чувствительность к допущению. Целевые ответы не доступны. H40 применена к S2.
