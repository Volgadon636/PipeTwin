H17 и H35 повторили соответственно H12 и H18 по прогнозам, поэтому их повторные значения исключены из рейтинга самостоятельных кандидатов. H18 и H39 почти совпадают по форме и ошибкам, поэтому основания считать их независимыми компонентами слабы. У H12 и H18 различия заметнее. ## Варианты выбора

- **Только S1.** H18 даёт максимальный сводный r² среди основных вариантов. H12 сохраняет больший r² на участке из 48 сегментов и меньшую MAE. Выбор между ними зависит от того, какой эффект нужно перепроверить при допустимом выравнивании целевой трубы.
- **Только S2.** H31 подходит для повторной проверки лидера ретроспективы. H38 — небольшое изменение базового прогноза с положительным сводным Δr² на обеих схемах. H22 — другой кандидат с приростом на обеих схемах и известным выходом за диапазон скорости.
- **По одному методу на кейс.** Исследовать локальную интеграцию H18 для S1 и H31 для S2, либо H12 для S1 и H38 для S2. У кейсов отдельные входы и метрики. Вариант с базой в любом из кейсов доступен, пока независимая проверка отсутствует.

H12, H18 и диагностический Ridge H16 представляют разные поправки к одному профилю S1. Их совместное включение требует отдельных проверок, поскольку поправки пересекаются по входам. H31 и H22 в S2 заменяют или расширяют одну пространственную компоненту. H38 меняет выход уже выбранной модели. Для оценки совместимости нужны отдельные измерения выбранных компонентов и комбинаций.

Для перехода к локальной интеграции укажите конкретный ID и кейс, например **H18 для S1 и H31 для S2**, либо **только H31 для S2**. Ограничение H31 действует для всех вариантов.
