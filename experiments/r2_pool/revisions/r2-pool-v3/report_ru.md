- **H01.** Для S1 нужна карта соответствия координат ВТД 2022 года оценочной сетке с источником, датой доступности до 01.12.2023 и покрытием всего участка `1250022871`. Для S2 действующие пространственные признаки и проверка не используют совмещение с прошлым ВТД целевой трубы. [Аудит H01](hypotheses/H01/summary.json)
- **H02.** По номерам записей повторно разобраны 48 040 строк и проверены `Distance`, `Relative Distance`, `Section Number`, `Wall Thickness`, `Residual Wall Thickness` и `Defect Depth in %`. Воспроизведено действующее преобразование долей в проценты для кампании 2018 года. Расхождений с очищенными значениями 0, включая совпадение пропусков. [Аудит H02](hypotheses/H02/summary.json)
- **H03.** В 14 239 строках ВТД сработал флаг расхождения поля стенки с паспортным номиналом. Для проверки нужны датированные границы вставок и документированный номинал в каждой зоне. Само поле `Wall Thickness` из строки ВТД не устанавливает конструкцию сегмента. [Правила очистки](../../../../docs/cleaning_rules.md) · [Аудит H03](hypotheses/H03/summary.json)
- **H04.** Проверено исключение двух исторических записей о несплошности поперечного шва. Обе относятся к 23.09.2018. Для S2 один минимум в обучении изменился с 3,76 до 6,26 мм, другой сегмент потерял обучающую метку. Всего осталось 371 из 372 обучающих строк. Изменились все 94 прогноза S2, r² снизился на всех шести участках с определимой метрикой. На седьмом участке был один сегмент. Сохранённая рекомендация ментора включает прошедшие проверки замеры на швах в минимум, поэтому подтверждённое исключение по H04 требует внешнего основания. [Рекомендация ментора](../../../../docs/mentor/sources/SRC-M2-STRICT-REVIEW.md) · [Аудит H04](hypotheses/H04/summary.json) · [Метрики S1](hypotheses/H04/seam_sensitivity/S1_peer_2023/metrics_by_profile.csv) · [Метрики S2](hypotheses/H04/seam_sensitivity/S2_retro_2023/metrics_by_profile.csv)
- **H05.** Для цели S1 есть 32 записи УЗТ до даты отсечения, все выше паспортного номинала и исключены проверкой качества. На двух участках ретроспективы соответственно 0 и 32 записи, пригодных также 0. Нужны подтверждённые объект, координата, дата и единицы измерения, а также объяснение превышения номинала. Замеры УЗТ целевой трубы вне контракта S2. [Аудит H05](hypotheses/H05/summary.json)
