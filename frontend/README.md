# PipeTwin — метрики и прогноз толщины

React + Vite + TypeScript + Recharts. Рабочая страница с метриками, факторами модели, списком опасных сегментов, валидацией и профилем толщины. Только десктоп, от 1280 px. Интерфейс читает пять JSON из `public/data/`; Python и исходные CSV в браузере не используются.

## Установка

Node **24.6.0** указан в `engines` и `.nvmrc`:

```powershell
cd frontend
nvm use 24.6.0
npm install
```

Готовые JSON включены в проект, поэтому для просмотра Python не нужен.

## Экспорт сохранённых результатов

Из корня репозитория, в существующем Python-окружении с pandas и numpy:

```powershell
.\.venv\Scripts\python.exe -m src.export_frontend_data
```

Либо в активированном окружении:

```powershell
python -m src.export_frontend_data
```

Для отдельного окружения зависимости экспортёра указаны в `frontend/requirements.txt`. Из `frontend/` с активированным Python доступна команда `npm run export:data`.

Экспортёр **не обучает модели, не вычисляет метрики и не создаёт новые прогнозы**. Он копирует сохранённые значения, преобразует структуру CSV/JSON для интерфейса, проверяет согласованность `result.csv` и диагностики и сверяет SHA-256 прочитанных источников до и после. Записываются только пять файлов `frontend/public/data/*.json`.

## Запуск и сборка

Из `frontend/`:

```powershell
npm run dev
npm run build
npm run preview
```

Dev-сервер: `http://127.0.0.1:5173`. Сборка: `frontend/dist/`. `base: './'` позволяет размещать статическую сборку в подкаталоге. JSON загружаются относительно базового URL.

## Проверки

Из корня:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s frontend/tests -v
```

Проверки сверяют экспорт с готовыми источниками, включая сохранённые метрики, прогнозы и рейтинг риска. Строгая проверка TypeScript входит в `npm run build`; Zod проверяет JSON при загрузке. Предусмотрены загрузка, сообщение об ошибке и повторная попытка.

## Работа со страницей

Порядок блоков: профиль толщины → опасные сегменты → прогноз–факт на валидации → факторы и сравнение моделей с метриками.

В таблице опасных сегментов нажмите номер сегмента или «Подробнее»: под строкой откроются границы участка, прогноз, P10/P90, дата и доступное прошлое ВТД. Повторное нажатие сворачивает карточку. Кнопка «Показать на профиле» выбирает соответствующую трубу и отмечает сегмент на верхнем графике. При смене фильтра, сортировки или страницы карточка закрывается.

## Структура

- `src/components/` — общие элементы интерфейса.
- `src/sections/` — пять блоков: факторы, сравнение моделей, опасные сегменты, валидация, профиль толщины с интервалом P10–P90.
- `src/charts/` — графики Recharts и подсказка с данными сегмента.
- `src/data/schema.ts`, `src/types/` — схемы и выведенные из них типы.
- `src/hooks/` — загрузка и проверка данных.
- `src/utils/` — форматирование и общие константы.
- `public/data/` — единственный источник чисел для интерфейса.
- `tests/` — сверка JSON с сохранёнными результатами.
