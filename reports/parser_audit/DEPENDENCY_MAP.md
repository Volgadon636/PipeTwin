# Preprocessing dependency map

Authoritative source: model_v02 at 2522d5fc2409ea54c5c6962f187a32c01dd0e7e3. Graph used first to locate the pipeline and its callers; all ten preprocessing source modules and tests then read. Graph review also traced ML/experiment entry points using the parser. The graph found parse_identifiers tested indirectly; the new end-to-end exact-ID regression covers that call path.

Original CSV → detection → parsing → normalization → cleaning → segment mapping → temporal processing → feature generation → validation → serialization.

| Transition / producing function | Input schema | Output schema and keys | Potential information loss / policy |
|---|---|---|---|
| config.FILE_ALIASES; format_detector.resolve_sources | Six canonical or explicitly listed organizer files | One path per canonical source | Conflicting alias contents rejected; identical CRLF/LF copies allowed. Hydraulic input has no sample_result alias. |
| detect_file_format | Bytes | UTF-8-sig or CP1251; comma/semicolon/tab | Unsupported decoding rejected. Inference is limited to these formats. |
| read_and_standardize_all; build_column_mapping | Original quoted CSV header/records | 426 mapped source columns across six tables; source_row logical ordinal; original names in manifest | Unknown columns retained as archival strings; normalized collisions receive hashes; canonical collisions fail. Empty/duplicate headers and malformed widths now fail. |
| parse_identifiers / parse_numeric / robust_parse_dates | Explicit NUMERIC_COLUMNS and DATE_COLUMNS | Nullable Int64 ID, float64 analytical quantities, datetime64[ns], string archive | Declared NA tokens become missing; invalid typed values retain source text and exact parse-failed issue. No failed conversions in supplied inputs. Float tolerances documented. |
| clean_datasets: passport | Unique ID; positive geometry; commissioning | Same 16 rows plus diagnostic archive flag | Invalid required geometry fails whole build. Current passport/profile are static assumptions, not historical versions. |
| clean_datasets: profile | ID, distance, elevation + archive | 20,180 retained; 38 duplicate exclusions; 0 quarantine | Only exact duplicate source records removed; coordinate conflicts fail. Source provenance survives. |
| clean_datasets: VTD / UZT | ID/date/distance/local and residual thickness | 48,040 / 67 retained; VTD quarantine 251; flags and raw depth | Out-of-bounds/missing-key rows quarantined, never moved. Residual measurements retained; eligibility masking separate. |
| clean_datasets: monitoring / hydraulics | ID/date/physical fields | 495 / 39,052 retained; identity/exposure/chronology/diameter flags | No guessed ID mapping; diameter meters→mm only when supported by passport. Time filtering deferred. |
| grid_builder.build_segments_grid | Passport ID, length_km | (id,segment_id), start/end/actual length: 4,668 rows | Length rounded to micrometer resolution; 10 m half-open intervals with endpoint in final segment. |
| assign_segments; map_vtd_to_segments; map_uzt_to_segments | Valid local coordinates + complete grid | (id,date,segment_id): 1,543 VTD groups, 3 UZT groups | Point assignment, not defect extent. Minima/counts/flags aggregate observations; full source-to-group lineage retained by audit. Duplicate clusters are not independent defects. |
| map_profile_to_segments | Clean sorted coordinates | Complete grid plus profile/geometry fields | Linear interpolation; constant endpoint extrapolation; integration loses point detail but raw profile retained. Extrapolation/gap flags provided. |
| temporal.hydraulic_asof | Clean archive, requested ID and cutoff | Pre-cutoff records, field-specific usable copies and quality log | Apply strict cutoff before consecutive-day soft rules. Hard invalids always missing in usable values. Original values retained. |
| hydraulic_summary | Pre-cutoff usable rows | One row per ID: daily medians, mean/std/coverage/gaps/counts | Equal observed-day weighting; missing days not synthesized. Long gaps remain visible. |
| map_monitoring_asof | Clean records and strict removal cutoff | One row per ID: candidates/usable count, chemical medians | No eligible monitoring records in supplied data; missing medians remain missing. |
| build_features_asof | Static/profile + temporal summaries + observed histories + request | (id,segment_id,prediction_date); 2,000 current target rows | Many-to-one static/summary joins and one-to-one history joins checked. Latest eligible diagnostics strictly before cutoff. Cold forbids all diagnostic history, including archive flags. |
| data_prep.run_pipeline: training_targets | Observed VTD aggregates | 1,080 eligible measured labels | No nominal/zero replacement for absent observations. Excludes chronology/heldout invalid groups. |
| validator.validate_and_summarize | Complete intermediate tables and requests | pipes_summary, validation: 270 checks | Reuses production conventions; independent audit is additional evidence, not this validator alone. |
| storage.save_table / validate_roundtrip | Typed DataFrames | 22 CSV/Parquet pairs plus manifest with exact schemas/hashes | CSV float output uses 15 significant digits, tolerated at atol 1e-10 / rtol 1e-12; integer IDs and timestamps exact. UTF-8. |
| data_prep publication; RepositoryData.read | Fully staged validated generation | Published output files and manifest | Caught failures rollback batch. Aborted root has marker, readers refuse it. Not a filesystem transaction or simultaneous-reader guarantee. |
| ml.windows.make_snapshot / build_training_windows | Each label date and eligible histories | Rebuilt historical X/y, explicit initial thickness and horizon | Nearest-prior fallback and nominal cold baseline are modeling assumptions, not measurements; excluded from rate fitting where specified. |
